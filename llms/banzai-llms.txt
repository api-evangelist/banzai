# Banzai

> Banzai International, Inc. (NASDAQ: BNZI) is a marketing technology company building
> AI-enabled engagement, video and event marketing software — Demio, Boost, Curate,
> Vidello, OpenReel, CreateStudio, PhotoVibrance, Twinkle and Act-On. Its one public
> developer surface is the Public Demio API: a key/secret authorized REST API for
> webinar Events, Sessions, attendee registration and attendance reporting.
>
> This file is generated by API Evangelist from the public Banzai/Demio surface. It is
> not published by Banzai. Provenance for every artifact is in the file's frontmatter.

## APIs

- [Public Demio API](https://publicdemioapi.docs.apiary.io): REST API at
  https://my.demio.com/api/v1. 7 operations across Events, registration and reporting.
  Auth is an account API Key + API Secret sent as `Api-Key`/`Api-Secret` headers.

## Specs

- [OpenAPI 3.0.3](openapi/banzai-demio-openapi.yml): API Evangelist conversion of the

## Artifacts

- [Authentication](authentication/banzai-authentication.yml): API key/secret pair,
  header or query transport, sandbox flag, SAML SSO for the web app only.
- [Conventions](conventions/banzai-conventions.yml): versioning, error envelope,
  filtering, custom fields — and the absences: no idempotency, no pagination, no
  request-id, no field expansion.
- [Error catalog](errors/banzai-problem-types.yml): the `{"messages": [...]}` envelope
  and every documented 400/401/403/404.
- [Rate limits](rate-limits/banzai-rate-limits.yml): 180 req/min burst; 100/day on a
  free trial, 5,000/day for customers, reset 00:00 UTC, shared with Zapier.
- [Data model](data-model/banzai-data-model.yml): Event, EventDate (Session),
  Registration, Participant and their relationships.
- [Lifecycle](lifecycle/banzai-lifecycle.yml): v1 in the path, status page, and the
  missing deprecation policy and changelog.
- [Conformance](conformance/banzai-conformance.yml): what the API does and does not
  conform to.
- [Sandbox](sandbox/banzai-sandbox.yml): the sandbox key/secret distinction visible in
  `GET /ping`, and the absence of a self-serve path to one.
- [Packages](packages/banzai-packages.yml): no official SDK in any language.
- [Events](asyncapi/banzai-demio-events.yml): Zapier-only event surface — no
  first-party webhooks, no AsyncAPI.
- [MCP candidate](mcp/banzai-mcp.yml) and

- [Agent skills](skills/_index.yml): register an attendee and return a join link; pull
